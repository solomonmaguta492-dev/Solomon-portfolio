
# Solomon Portfolio

A personal portfolio website built with HTML, CSS, and JavaScript to showcase my work and skills.

## Live Demo

[View the portfolio](https://solomonmaguta492-dev.github.io/Solomon-portfolio/)

## Features

- Presents portfolio projects and personal information
- Styled with CSS
- Includes JavaScript for interactive behavior

## Technologies

- HTML
- CSS
- JavaScript

## Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## What I Learned

I practiced structuring a website with HTML and styling it with CSS. I also learned how JavaScript can add interactive behavior to a page.
